# DESIGN AUDIT — LiveWalls

**Дата:** 2026-10-21 · **Проект:** LiveWalls (сайт-визитка macOS-приложения) · **Репозиторий:** `Karkatov/LiveWalls` → `/Users/duxxless/LiveWallsSite`
**Режим сборки:** статический экспорт (`output: 'export'` → `out/`), хостинг — Cloudflare Pages.

Проход 1 = исследование + план. Код в этом проходе не менялся (изменён только этот файл).

---

## 0. Резюме

Сайт технически крепкий: корректная локализация, полная сборка 109 статических страниц, продуманные метаданные, работающие тесты (25 unit + 7 E2E), нулевая зависимость от внешних API. Но **по визуальному языку это типичный «AI-сайт»**: тёмный фон + фиолетово-циановый градиент на каждом втором элементе + одинаковые полупрозрачные карточки с `backdrop-blur` + одна системная гарнитура на всё.

Главные проблемы (в порядке влияния на восприятие):

1. **Нет визуальной идеи.** Градиент `#7C5CFF → #22D3EE` применён к кнопкам, бейджам, иконкам, eyebrow-пилюлям, CTA-плашке, логотипу и тексту заголовка. Ничего не выделяется, потому что выделяется всё сразу. Продукт — «живые обои», то есть движение и свет, а сайт выглядит как статичная сетка карточек с подсветкой.
2. **Типографика отсутствует как система.** Один системный шрифт (`ui-sans-serif`), размеры разбросаны (`text-3xl` → `text-6xl` без шкалы), `tracking-tight` на всём подряд, `clamp()`-шкала существует в `src/styles/theme.ts:79-102`, но **не используется ни в одном компоненте** — мёртвый код.
3. **Компонентная база рассыпается.** 37 ручных копий «карточки» (`border-border/6x bg-card/4x rounded-2xl border p-6 backdrop-blur-xl`) с четырьмя разными прозрачностями и четырьмя разными радиусами; `ui/card.tsx` не используется ни разу; у каждой Radix-обёртки **animations не работают** (см. §4, дефект P0-1).

Вывод: нужен не «редизайн покраски», а **смена арт-дирекшена** + выборочный ремонт инфраструктуры. Предлагаю направление **A «Kinetic Cinema»** (§6).

## 2. Архитектура (что уже хорошо — не ломать)

- **14 маршрутов × 2 локали = 109 статических страниц** (34 обоев × 2, 5 паков × 2, 3 legal × 2, 9 статических × 2 + `/_not-found`, `/robots.txt`, `/sitemap.xml`).

## 3. Аудит по осям

### 3.1 Арт-дирекшн и идентичность

| Симптом                                                                                                | Где                                                                                                                                                                                                                     |
| ------------------------------------------------------------------------------------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Фиолетово-циановый градиент на кнопке, бейдже, иконке, eyebrow, CTA-плашке, логотипе, тексте H1        | `ui/button.tsx`, `ui/badge.tsx`, `home/hero.tsx:44`, `home/categories-grid.tsx`, `home/features-grid.tsx`, `shared/section-heading.tsx`, `shared/empty-state.tsx`, `onboarding/onboarding-modal.tsx`, `shared/logo.tsx` |
| `text-gradient` + `bg-gradient-brand bg-clip-text text-transparent` — два способа сделать одно и то же | `home/hero.tsx:44`                                                                                                                                                                                                      |
| Скриншот приложения показан в «браузерной» рамке с тремя кружками (macOS-клон Google Chrome)           | `home/hero.tsx:92-98`                                                                                                                                                                                                   |
| Одинаковые полупрозрачные карточки с `backdrop-blur-xl` — 37 копий                                     | по всему `src/components/**`                                                                                                                                                                                            |
| 12 градиентных плейсхолдеров одинаковой яркости — как «обои» не читаются                               | `public/placeholders/wallpapers/*.svg`, `src/styles/theme.ts:105-118`                                                                                                                                                   |

**Вердикт:** интерфейс и контент конкурируют за внимание. Премиальный каталог обоев должен быть **нейтральным**: цвет живёт внутри кадров, UI — «проекционный свет» вокруг них. Плюс главный актив продукта — движение, а на сайте нет ни одного движущегося пикселя: `preview` у всех 34 обоев = `null`, поэтому «живые» обои выглядят как статичные картинки.

### 3.2 Типографика

- **Одна гарнитура** на весь сайт: `--font-sans: ui-sans-serif, -apple-system, … 'SF Pro Display', 'Inter', …` (`globals.css:137-140`). Нет ни заголовковой, ни моно-гарнитуры.
- **Шкала не применяется:** `src/styles/theme.ts:79-102` описывает `display` / `title` / `sectionTitle` / `body` с `clamp()`, но эти константы не импортируются ни в одном компоненте. Вместо неё — разброс `text-4xl sm:text-5xl lg:text-6xl` в Hero и `text-3xl sm:text-4xl` в SectionHeading.
- **Нет оптической иерархии:** все заголовки `font-bold tracking-tight` — разница между H1 и H2 только в размере; нет контраста плотности/начертания.
- **Нет «мелких» системных размеров:** 12 px eyebrow, 11 px бейдж видео, `text-[11px]`/`text-[13px]`/`text-[14px]` — ручные значения в 6 местах.
- **Нет моно-шрифта** там, где он нужен: цены, «4K», «24 ч», номера кадров, параметры файла, таймкод — сейчас это обычный текст, хотя это идеальные кандидаты для моно.
- **Микротекст на градиенте:** в `public/index.html` и в CTA заголовок набран `text-transparent` поверх `bg-clip-text` — при `prefers-reduced-motion`/отсутствии шрифта риск «пустого» текста.

### 3.3 Цвет

- **Один бренд-градиент на всё** (`--brand-from/-via/-to` + `--brand-glow/-strong`). Нет нейтральной шкалы (сейчас 6 полутонов через `rgba(255,255,255,α)`), нет семантических цветов (успех/предупреждение/премиум).
- **`--brand-foreground` не существует** → 22 no-op класса в 15 файлах: бейдж `variant="brand"` выглядит как обычный серый, eyebrow-пилюли не имеют фиолетового текста, иконка `Check` в селекте белая.
- **Светлая тема** существует, но построена как инверсия тёмной (`#f7f7f9` / `#101014`), а не как самостоятельная палитра.
- **Контраст:** `rgba(245,245,247,0.62)` на `#0a0a0c` ≈ 7.3:1 ✓, но `text-muted-foreground/40` для неактивных звёзд ≈ 2.6:1 — ниже порога для неинтерактивного текста.
- **Цена в интерфейсе:** 890 ₽ набирается `font-bold` того же шрифта, что и обычный текст — нет ощущения «веса» денег.

### 3.4 Композиция и сетка

- Контейнер **1200 px** (`max-w-[1200px]` × 19) — для премиального каталога обоев мало; рабочая ширина 1440 при 1280–1360.
- **Ритм секций:** `py-16 … lg:py-24` — одинаков на всех семи секциях главной (`page.tsx:68`, `categories-grid.tsx:40`, `cta-banner.tsx:14`, `featured-wallpapers.tsx:17`, `features-grid.tsx:32`, `hero.tsx:32`, `reviews.tsx:15`). Нет контраста между «плотными» и «воздушными» секциями.
- **Нет вертикального ритма внутри секций:** заголовок → контент почти всегда `mt-8`/`mt-10`; ручная настройка каждого отступа вместо шкалы.
- **Главная — «стопка одинаковых блоков»**: 7 секций, у каждой свой `SectionHeading` с eyebrow-пилюлей → визуально страница читается как шаблон.
- **Каталог:** сетка `sm:2 lg:3 xl:4` при контейнере 1200 → карточки ~270 px шириной; для 16:9-кадра этого мало, превью размываются.
- **Страница обоев:** превью и характеристики в одном столбце; нет «постера» на весь экран, ради которого открывают этот раздел.
- **Ширина строки текста** не контролируется: `max-w-xl`, `max-w-2xl`, `max-w-3xl` в разных местах.

### 3.5 Компоненты и консистентность

- **`ui/card.tsx` — 0 использований.** Вместо него 37 ручных копий с 4 вариантами прозрачности (`/30 /40 /50 /60`) и 4 радиусами (`rounded-xl / 2xl / 3xl / full`).
- **Мёртвый код:** `src/styles/animations.ts` (109 строк, 0 импортов; докблок ссылается на несуществующий `src/lib/hooks/use-reduced-motion.ts`), `ui/sheet.tsx` (89 строк, 0 использований), `ui/separator.tsx`, `WallpaperCardSkeleton`/`TableRowSkeleton`, `src/lib/hooks/use-media-query.ts` (4 хука, 0 потребителей), `VideoBadge` в `wallpaper-media.tsx` (дублирует инлайн-разметку в двух других местах), `usePaymentProvider()` (всегда `'none'`).
- **Мобильное меню** (`header.tsx:121-169`) написано руками, хотя `ui/sheet` уже реализован — и именно в нём сломана анимация.
- **Дублирование UI:** `ThemeOption` в онбординге, `SocialLink` в футере и кнопки пагинации в каталоге — свои реализации вместо `ui/button`; глобальный 404 (`app/global-not-found.tsx`) вообще на инлайн-стилях с копией брендовых hex-цветов.
- **Баг копипасты:** `home/features-grid.tsx` — `t('description')` выводится дважды (в `SectionHeading` и в нижней плашке).
- **Дубликат SVG-`id`:** `shared/logo.tsx` — фиксированный `id="lw-grad"`, логотип рендерится дважды (шапка + футер) → два gradient-`id` в DOM.
- **`blurDataURL` захардкожен:** все пакы используют `pack-01.svg`, все скриншоты — `app-main.svg` → при загрузке «прыгает» один и тот же кадр.

### 3.6 Motion

- **Единого motion-языка нет.** `src/styles/animations.ts` объявляет 12 вариантов (`fadeUp`, `scaleIn`, `parallax`, `cardHover`, `pageTransition`, `reducedVariants`…) — **ни один не используется**. Реальные анимации продублированы инлайном в `shared/motion.tsx` с другими числами (y 26 vs 24, duration 0.65 vs 0.4, stagger 0.08 vs 0.07).
- **Нет параллакса, нет scale-in, нет shared-element.** Только `whileInView` с `y` и одна `layoutId` в шапке.
- **`prefers-reduced-motion` обрабатывается в 4 файлах** вручную (каждый по-своему) + глобально в CSS (обнуляет CSS-анимации, но не Framer Motion).
- **Видео-превью без учёта reduced-motion:** `wallpaper-media.tsx` — `<video muted loop autoplay>` без проверки; сейчас не видно (все `preview = null`), но при подключении API — сразу a11y-регресс.
- **60 FPS под вопросом:** `backdrop-blur-xl` на каждой из 37 карточек + `blur-3xl` ореолы в hero → на мобильных это просадка кадров и лишние слои композиции.

### 3.7 Медиа и контент

- **Плейсхолдеры плоские:** 12 линейных градиентов, 1.1 КБ каждый. Как обои не воспринимаются: нет глубины, нет света, нет движения, нет «кадра».
- **Скриншоты приложения** — 4 SVG с обрезками интерфейса, один (`app-main.svg`) используется и в hero, и как blur для всех скриншотов в разделе «О приложении».
- **`sizes` не задан** в 3 из 6 мест (`hero.tsx:100`, `reviews.tsx:44`, `about/page.tsx:74`).
- **Видео-каталога нет:** 29 из 34 обоев — видео, но превью только статичные постеры.
- **Локализация контента отсутствует:** названия/описания 34 обоев, 9 категорий, 5 паков, 6 отзывов — только на русском; на `/en/wallpapers` карточки русские. Форматирование дат/цен — `ru-RU` даже на `/en`.

### 3.9 Доступность

- Кнопки пагинации `←` / `→` **без `aria-label`** (`catalog-browser.tsx`).
- `prefers-reduced-motion` — не системный (см. 3.6).
- `text-muted-foreground/40` (неактивные звёзды) — ниже 3:1.
- Глобальный `focus-visible` есть ✓ (2 px, offset 2), но у `select`/`dropdown` собственные `ring` перебивают его.
- Онбординг-модалка помечает остальные элементы `aria-hidden` → контент под модалкой недоступен для скринридера, пока модалка открыта (ожидаемо, но нужно `aria-modal`/`DialogTitle` ✓ Radix даёт).

### 3.10 Контент и IA

- Навигация: 6 пунктов (`wallpapers`, `packs`, `pricing`, `about`, `faq`, `support`) + «Скачать» в шапке ✓, но `/download` нет в меню как раздела, а `legal`/`account`/`admin` спрятаны в футере — приемлемо.
- **Нет «быстрого просмотра»** — в каталоге есть ключ `catalog.quickView`, но функции нет: единственный путь к обоям — клик по карточке (переход на отдельную страницу). Для каталога обоев это главный недостающий жест.
- `/ru/wallpapers` отдаёт **весь список (34)** и фильтрует в браузере ✓ (нормально для моков, но при 300+ обоях потребует сервера).
- Соцсети в `siteConfig.SOCIAL` — заглушки `#`; домен `livewalls.app` — плейсхолдер; реквизиты — нули.

## 4. Функциональные дефекты (чинятся независимо от арт-дирекшена)

**P0 — ломает интерфейс**

1. **Анимации Radix не работают** (`animate-in/fade-in-0/zoom-in-95/slide-in-from-*/animate-accordion-*` → 0 правил в CSS). Затронуты: онбординг-модалка, меню темы, меню языка, 4 селекта фильтров, тултип «в избранное», аккордеон FAQ, `ui/sheet`. _Решение без новых зависимостей_: написать собственные keyframes + `[data-state='open'|'closed']` селекторы в `globals.css`.
2. **`text-brand-foreground` не существует** → 22 no-op класса в 15 файлах. _Решение_: завести токен в `@theme inline` (в новой палитре — переименовать, чтобы старые no-op не маскировались).

**P1 — заметно на проде** 3. `home/features-grid.tsx` — `t('description')` продублирован. 4. `shared/logo.tsx` — дубликат `id="lw-grad"` в DOM. 5. `catalog-browser.tsx` — у кнопок пагинации нет `aria-label`. 6. `src/lib/utils/format.ts` — даты/цены всегда `ru-RU`; `src/lib/catalog/filters.ts:70` — сортировка по имени всегда по-русски. 7. `wallpaper-media.tsx` — `<video>` без учёта `prefers-reduced-motion`. 8. `blurDataURL` у всех паков и скриншотов одинаковый. 9. `sizes` не задан у 3 изображений.

**P2 — чистка** 10. Мёртвый код: `src/styles/animations.ts`, `ui/sheet.tsx`, `ui/separator.tsx`, скелетоны, `use-media-query.ts`, `VideoBadge`, `usePaymentProvider`. 11. 37 ручных копий карточки → `ui/card` (или новый `Surface`). 12. Неиспользуемые CSS-утилиты: `.glass`, `.glow-brand(-strong)`, `.mask-fade-*`, `.no-scrollbar`, `@keyframes marquee/float/pulse-glow` (или задействовать, или удалить).

## 5. Критерии «как должно выглядеть»

1. **Один визуальный язык:** нейтральный интерфейс + цвет только в медиа.
2. **Три масштаба типографики** с чёткой ролью (дисплей / UI / мета-моно) и `clamp()`-шкалой, применённой ко всем страницам.
3. **Секции отличаются друг от друга** ритмом, а не только содержимым.
4. **Каждое движение объяснимо:** вход, подтверждение, смена состояния — никакого «анимационного шума».
5. **Карточка обоев = кадр:** номер, время, метаданные, один hover-жест, один жест открытия.
6. **Ни одной «сломанной» анимации** (сейчас их 6 видов).
7. **Сайт выглядит так же хорошо в светлой теме** — значит, палитра должна быть продумана в обеих.
8. **Ни одного лишнего запроса** наружу: шрифты локально, картинки локально, аналитика — выключена.

## 6. Три варианта арт-дирекшена

### Вариант A — «KINETIC CINEMA» (рекомендую)

**Идея.** Сайт как **просмотровый зал**: тёмный нейтральный зал, в котором единственный источник цвета — сами обои. Оформление — кинематографическая «разметка» кадра: тонкие линии-хайрлайны, номера кадров и таймкод моно-шрифтом, 16:9-кадры с «проекционным» светом, зерно плёнки. Не «тёмный AI-сайт», а **инструмент для выбора кадра** — как в профессиональных каталогах стокового видео, где интерфейс почти невидим, а работает изображение.

**Типографика**

| Роль       | Гарнитура                                 | Почему                                                                                          |
| ---------- | ----------------------------------------- | ----------------------------------------------------------------------------------------------- |
| Дисплей    | **Playfair Display** (переменная 400–900) | Высокий контраст штрихов = «киношрифт»; **есть кириллица** ✓; хорош в больших кеглях (72–96 px) |
| Текст/UI   | **Manrope** (переменная 200–800)          | Нейтральный гуманистический гротеск, **отличная кириллица**, не спорит с дисплеем               |
| Мета/техно | **JetBrains Mono** (переменная)           | Таймкод, номера кадров, цены, «4K», параметры файла, eyebrow-метки                              |

**Почему локально, а не `next/font/google`:** Google Fonts тянутся во время билда → падение внешней сети = падение деплоя на Cloudflare. Кладём `woff2` (latin + cyrillic) в репозиторий и используем `next/font/local`: ноль внешних запросов, `size-adjust` против CLS, preload, полный контроль над весом.

**Цвет**

```
--ink-900 #07080A   фон (почти чёрный, холодный)
--ink-800 #0C0D10   секции
--ink-700 #14161A   поверхности (матрицы, поля)
--ink-600 #1E2126   границы, хайрлайны
--paper    #F4F2ED  текст (тёплый белый — не #F5F5F7)
--paper-dim  rgba(244,242,237,.64)
--paper-faint rgba(244,242,237,.38)
--signal  #E7B24B   единственный акцент: «свет проектора» (янтарь)
--signal-soft rgba(231,178,75,.14)
--live    #E0523F   редкий второй акцент: метки «Видео»/«Premium»
```

Насыщенный цвет — **только внутри кадров** (плейсхолдеры и скриншоты). Логотип перестаёт быть градиентной заливкой → монограмма + тонкая световая линия.

**Композиция**

- Контейнер **1280 px** (сетка 12 колонок), кадры 16:9, поля 24/48/96 px.
- Асимметрия 7/5: текст 7 колонок, медиа 5 (или наоборот — чередование по секциям).
- **Редакционная разметка:** вертикальный хайрлайн слева с моно-подписью (`01 / 05`), нумерация секций, «выноски» в виде тонких линий к медиа.
- Ритм секций чередуется: плотная (каталог) → просторная (манифест) → средняя (отзывы).

**Motion language**

- Кривые: `--ease-expo cubic-bezier(.16,1,.3,1)` (появление), `--ease-soft cubic-bezier(.32,.72,0,1)` (переходы), пружина `{stiffness:140, damping:22}` (тактильные).
- **Reveal через маску:** обёртка `overflow:hidden`, текст `translateY(110% → 0)`, 720 мс, expo — «шторка», а не «fade».
- **Hero:** 5 слоёв старта (метка → строка 1 → строка 2 → подзаголовок → CTA → мета-полоса), шаг 70–90 мс; «проекторный луч» медленно проходит по кадру (CSS, 9 с, бесконечно); мокап «дышит» (scale 1 → 1.02, 24 с, alternate).
- **Скролл:** секции раскрываются с 60 px; тонкий **скролл-таймкод** слева (1 px + моно-проценты) — метаморфоза кинометафора; лёгкий параллакс кадра (−12 % высоты).
- **Микро:** кнопка — световой блик (`::after`, 600 мс) + `scale(.985)` на нажатии; карточка — кадр `scale(1.045)` за 800 мс, мета-строка выезжает на 6 px, номер кадра становится таймкодом; пункт меню — подчёркивание на `layoutId` + микро-сдвиг ±2 px.
- **Reduced motion:** единый провайдер `useMotionPref()` + CSS-фолбэк; ничего не «прыгает».

**Плюсы:** уникальное лицо (не шаблон), честно отражает продукт (движение и свет), отлично работает с существующими SVG-плейсолдерами (они станут единственным источником цвета), не требует новых зависимостей.
**Минусы/риски:** нужен редизайн плейсхолдеров (иначе градиентные «обои» смотрятся бедно в кинематографичной рамке); тёмная тема требует внимания к контрасту; Playfair на кириллице — начертание «журнальное», не «технологичное» (альтернатива — Manrope для дисплея).

### Вариант B — «LIQUID GLASS / macOS NATIVE»

**Идея.** Обещание продукта — «родное приложение macOS». Интерфейс воспроизводит язык Sonoma: полупрозрачные «острова» (islands), непрерывные скругления, `backdrop-filter` как главный материал, пружинная физика, крупные системные контролы, SF-Pro-подобная типографика.

**Плюсы:** мгновенно «премиально» на скриншоте; нативно для macOS-аудитории; минимальные затраты — текущий сайт уже на 70 % здесь.
**Минусы:** **это не редизайн, а подтверждение текущего состояния** — те же стеклянные карточки, тот же фиолетовый градиент, тот же blur. Не создаёт нового лица; не решает главную проблему (нет идеи, нет движения); `backdrop-filter` на десятках поверхностей бьёт по INP; на macOS-сайте «стекло» без контекста = пустота. **Рекомендую использовать как источник микровзаимодействий (пружины, focus-ring, состояния контролов), а не как направление.**

---

### Вариант C — «EDITORIAL PRINT / ЖУРНАЛЬНАЯ БУМАГА»

**Идея.** Сайт как печатный журнал: светлая бумага (#F4F1EA), заголовки Playfair/Golos, тонкие линейки, поля с колонцифрами, номера, сноски, «паспорт приложения» вместо карточек-фичей. Контент (каталог, цены, legal, FAQ) выигрывает от редакционной подачи, а премиум-ощущение даёт типографика, а не эффекты.

**Плюсы:** редко и уверенно; отлично ложится на каталог/цены/документы; даёт «журнальную» иерархию, которую можно перенести в тёмную тему.
**Минусы:** метафора не про продукт (бумага vs движение); светлая тема становится основной — а продукт «живых обоев» тёмный и кинематографичный; нет места для «вау» на первом экране; риск выглядеть как блог/портфолио. **Рекомендую использовать как источник редакционной иерархии: хайрлайны, нумерация, колонцифры, «паспорт», индексация — в тёмной схеме варианта A.**

---

### 6.1 Решение

**Берём A «Kinetic Cinema»**, усиливая его:

- **из C** — редакционную строгость (хайрлайны, нумерация секций, моно-подписи, «паспорт» вместо карточек-фичей);
- **из B** — качество микровзаимодействий (пружины, точные focus/hover/pressed, контролы как нативные).

**Почему не A+B в равных долях:** стекло (B) и бумага (C) — два разных материала; смесь даёт «дизайн-систему-лоскутное одеяло». Один материал (тёмный зал) + одна техника (свет и кадр) дают узнаваемость.

**Порядок реализации:** сначала фундамент (шрифты, токены, motion-примитивы) — иначе каждая следующая секция будет переделываться дважды.

## 7. Дизайн-система (что будет создано)

### 7.1 Токены

**Цвет** (`globals.css`, `@theme inline`): нейтральная шкала `ink-900…ink-600`, бумажная шкала `paper / paper-dim / paper-faint`, акценты `signal / signal-soft / live`, семантика `success / warning / danger`, поверхности `surface-1 / surface-2 / hairline`, стекло только для 2–3 поверхностей (шапка, модалка, тост) — **не на каждой карточке**.

**Типографическая шкала** (роли, а не размеры):

```
display-xl  clamp(3.25rem, 7.5vw, 6rem)     / 0.95 / -0.035em   Playfair 500
display-lg  clamp(2.5rem, 5vw, 4rem)         / 1.02 / -0.03em    Playfair 500
display-md  clamp(2rem, 3.2vw, 3rem)         / 1.08 / -0.025em   Playfair 500
section     clamp(1.5rem, 2.2vw, 2.125rem)   / 1.15 / -0.02em    Manrope 700
lead        clamp(1.125rem, 1.4vw, 1.375rem) / 1.55              Manrope 400
body        1rem / 1.65                     Manrope 400
meta        0.8125rem / 1.4 / 0.06em        Manrope 600 (uppercase)
mono        0.75rem / 1.2                  JetBrains Mono 500
```

Плюс `text-balance` для заголовков, `text-pretty` для лида, `tabular-nums` для цен и параметров.

**Сетка и ритм:** `--container: 1280px`, `--gutter: 24px`, `--section-y: clamp(64px, 9vw, 144px)`, `--section-y-lg`, `--space-1…12` (4 px-шаг), `--radius-sm/md/lg/xl` (8/12/16/24), `--hairline: 1px`.

**Тени/свет:** вместо «мягких» — **контрастные**: `--shadow-frame` (глубокая тень под кадром), `--shadow-float`, `--glow-signal` (янтарное свечение только на интерактивных акцентах).

**Motion:** `--ease-expo`, `--ease-soft`, `--dur-fast: 160ms`, `--dur-base: 280ms`, `--dur-reveal: 720ms`, `--spring: 140/22`.

### 7.2 Компонентные изменения

- `ui/surface` (вместо ручных копий карточки): варианты `frame` (медиа-кадр), `panel` (панель), `row` (строка), `chip` (метка).
- `ui/button`: варианты `solid` (бумажный, высокий контраст), `signal` (янтарный акцент), `ghost`, `link`; состояния hover/active/focus/disabled/loading; блик на hover.
- `ui/badge`: `neutral / signal / live / premium`; mono-шрифт для технических меток.
- `ui/modal` (Radix + собственные keyframes): появление 220 мс expo, `focus-trap` ✓, `prefers-reduced-motion` ✓.
- `ui/select`, `ui/dropdown`, `ui/tooltip`, `ui/accordion`: **собственные keyframes** вместо отсутствующих `animate-in`.
- `shared/motion`: единые `Reveal`, `Stagger`, `MaskReveal`, `Parallax`, `useMotionPref`.
- `catalog/wallpaper-card`: **кадр** с номером/таймкодом, мета-строкой и одним hover-жестом; **quick-view модалка** с shared-element (`layoutId` между карточкой и модалкой — работает в статике, без View Transitions API).
- `layout/header`: «плёнка» вместо стекла — 1px хайрлайн, фон появляется после скролла, активный пункт — тонкая линия + моно-индекс.

### 7.3 Медиа

- Плейсхолдеры → **«живые» кадры**: SVG с внутренней CSS-анимацией (медленный дрейф градиента, лёгкий grain), отключаемой через `@media (prefers-reduced-motion)` внутри SVG. Анимация внутри `<img>` работает без JS ✓.
- Палитра плейсхолдеров → кинематографичная (глубокие teal/amber/magenta/монохром) вместо 12 одинаковых фиолетово-циановых.
- Скриншоты приложения → 4 честных кадра UI (каталог, плеер, bend-эффект, меню-бар), единый стиль.

## 9. Риски и митигации

| Риск                                                | Вероятность | Митигация                                                                                                                                        |
| --------------------------------------------------- | ----------- | ------------------------------------------------------------------------------------------------------------------------------------------------ |

## 10. Критерии приёмки (измеримые)

1. `npx next build` → папка `out/` создаётся, ≥ 300 файлов, без ошибок и предупреждений о мёртвых классах.
2. `npm run lint` / `typecheck` / `npm test` / `npm run test:e2e` — зелёные.
3. **0** классов-ноопов в собранном CSS: проверка grep'ом по `out/_next/static/css/*.css` на `animate-in`, `brand-foreground` и т. п.
4. **≥ 3 уровня типографики** (дисплей / UI / моно) — видно в computed-стилях, а не «на глаз».
5. **0** ручных копий карточки вне `ui/surface` (grep по `bg-card/`).
6. Все Radix-оверлеи анимируются (визуально + наличие keyframes в CSS).
7. `prefers-reduced-motion` → нет параллакса, нет бесконечных анимаций, всё читаемо.
8. Мобильная версия (360 px): нет горизонтального скролла, CTA на первом экране, навигация — боковая панель с анимацией.
9. LCP < 2.5 s, CLS < 0.1, INP < 200 мс ( Lighthouse, мобильный эмулятор).
10. Ни одного внешнего запроса на первой загрузке (шрифты, картинки, скрипты — свои).
